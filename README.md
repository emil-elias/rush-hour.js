# Rush Hour - a browser game

Catch your next subway train before it departs, but avoid running into ticket inspectors, as you don't have a ticket! They'll only let you go, if you bribe them, so make sure to collect some spare money, just in case. Also keep a distance to the toxic subway rats, they may be detrimental to your health...

--

This is a Javascript translation of a Processing game developed in the first semester of my media informatics bachelor (2021/22), so don't expect high code quality. Co-authors are Leonard Kiefner (Code) and Thorben Meier (Illustrations).

Right now it only contains one level, but further levels can easily be added following the same scheme in levels.json and with some slight adjustments to the game loop in main.js.
